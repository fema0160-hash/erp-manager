# ERP Manager

Squelette initial d'une application web de gestion des marchés.

## Périmètre actuel

Cette première étape fournit uniquement :
- une page Tableau de bord ;
- une barre latérale avec les futurs menus visibles mais désactivés ;
- une base PHP simple, sans dépendance externe ;
- une interface en français, adaptée à XAMPP.

Aucun module métier, aucune connexion à la base de données et aucune gestion d'utilisateur ne sont activés à ce stade.

## Installation locale (XAMPP)

1. Copier le dépôt dans `C:\\xampp\\htdocs\\erp-manager`.
2. Démarrer Apache depuis XAMPP.
3. Ouvrir : `http://localhost/erp-manager/`.

La page d'accueil redirige vers le dossier public.
